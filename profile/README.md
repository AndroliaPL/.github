# ![Androlia](https://raw.githubusercontent.com/AndroliaPL/.github/refs/heads/main/profile/title.png?v=1)

Androlia is a Minecraft **OneBlock server**.

---

## ~ About

This project was originally started in 2019 and is now developed [yokii](https://github.com/yokiidev) and [mushurelie](https://github.com/mushurelie).

---

## ~ Repository Content

This repository contains:
- server configurations
- public plugins
- some custom systems
- development tools

---

Some plugins will NOT be open-source for security reasons.
